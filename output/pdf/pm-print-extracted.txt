Project 01 · J-OS · 핵심 기여 01
요약과 원문을 구분하고, 검색 결과에 근거 위치를 붙였습니다.
01 요약을 원문과 같은 사실로 취급하지 않았습니다.
파생 기억의 출처를 남겨 원문으로 되짚을 수 있게 했습니다. 어떤 자료가 답변의 근거인지 확인하는 구조입니다.
02 검색과 실행을 하나의 서비스 흐름으로 연결했습니다.
문서 버전·인용 ID와 구절을 전달합니다. API가 실행 모듈을 불러 수행하고 SQLite에 단계와 결과를 저장합니다.
01 · 입력
대화와 등록 자료
요청·이전 결정·원문을 보존
02 · 기억
원문과 파생 정보 분리
출처 해시·원문 범위·처리 위치 기록
03 · 검색
근거 구절 선택
범위·활성 버전·인용 위치 전달
04 · 응답·실행
답변과 역할별 검토
도구 실행 단계·결과 보존

Project 01 · J-OS · 핵심 기여 02
중단된 작업을 이어가고, 완료한 결과는 보존했습니다.
01 작업 순서와 실행 한도를 정했습니다.
먼저 끝나야 하는 작업과 독립적으로 진행할 작업을 나눴습니다. 단계별 결과를 저장하고 실행
시간과 모델 호출 횟수에 한도를 두었습니다.
02 같은 작업을 중복 실행하지 않도록 했습니다.
요청과 실행 상태를 확인해 중복 실행을 막았습니다. 다시 시작할 때는 완료한 결과를
재사용하고, 실패한 작업과 관계없는 단계는 계속 진행하게 했습니다.
EXECUTION STATE
완료 · 산출물·근거 보존
부분 완료 · 단계별 분리
실패 · 원인·재개 위치
중단·실패 상황을 재현해 확인했습니다.
취소 후 재시작, 일부 단계 실패, 호출 한도 초과를
재현했습니다. 완료된 결과와 남은 작업을 구분해
이어갈 수 있는지 확인했습니다.
업데이트 과정에서 데이터를 지켰습니다.
운영 서버에 새 버전을 적용하며 데이터베이스를 백업하고, 별도 환경에서 복원을
확인했습니다. 요청을 접수하는 방식도 개선해 서비스에 반영했습니다.
