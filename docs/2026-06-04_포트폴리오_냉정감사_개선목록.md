## 전체 진단

현재 사이트는 OS 컨셉과 인터랙션 완성도는 눈에 띄지만, 채용 포트폴리오 관점에서는 핵심 정보 도달성이 낮다. 면접관은 첫 화면에서 직무, 강점, 대표 프로젝트, 증빙을 빠르게 확인해야 하는데, 현재는 잠금 화면, 빈 데스크톱, Dock, 창 조작이 먼저 나온다.

가장 큰 문제는 미완성 신호다. 이력서 PDF 준비 중, Portfolio AI 로컬 모델 미연결, Contact의 Blog/Email 업데이트 예정, 프로젝트 상세의 외부 링크 없음/미디어 없음은 모두 신뢰를 직접 깎는다.

두 번째 문제는 설명의 밀도다. 문제 정의, 요구사항, 화면 흐름, API 기준이라는 표현은 반복되지만 실제 산출물, 본인 기여 범위, 결과, 링크가 부족하다. 면접관은 "그래서 뭘 잘한다는 거지?"라고 느낄 수 있다.

세 번째 문제는 정체성 분산이다. 루트와 직무 트랙에서 공공 디지털 서비스기획, 주니어 PM/APM, 정책지원관, 국회 보좌관이 비슷한 비중으로 노출된다. 지원 직무별 URL 분리는 좋은 방향이지만, 루트에서는 대표 직무 하나가 더 강해야 한다.

## / 홈

### 첫 진입 잠금 화면

- 위치: `/` 첫 진입 잠금 화면
- 문제: 첫 화면에 이름과 `Client Portfolio`만 보이고 직무, 강점, 대표 프로젝트, 증빙이 없다. 채용 포트폴리오인데 첫 행동이 `잠금 해제`다.
- 면접관이 받을 인상: "컨셉은 만들었는데, 내가 왜 클릭해야 하는지 모르겠다."
- 심각도: Critical
- 수정 방향: 잠금 화면을 제거하거나, 잠금 화면 자체를 채용용 히어로로 바꾼다.
- 바로 적용할 문구 또는 디자인 수정안: `공공 문제를 요구사항·화면·API 기준으로 번역하는 서비스기획자 이재호입니다. 부산참여연대 3년 10개월 + SSAFY Android/Web 프로젝트 4건.`

### 잠금 해제 후 데스크톱

- 위치: `/` 잠금 해제 후 데스크톱
- 문제: 빈 배경과 Dock만 남는다. 핵심 정보가 기본으로 열리지 않는다.
- 면접관이 받을 인상: "예쁜 배경은 알겠는데 그래서 뭘 봐야 하지?"
- 심각도: High
- 수정 방향: 잠금 해제 후 About 또는 대표 프로젝트 창을 기본으로 연다.
- 바로 적용할 문구 또는 디자인 수정안: 첫 창 제목을 `3초 요약`으로 두고 `지원 직무 / 대표 역량 / 대표 증빙 3개`를 바로 노출한다.

### 모바일 홈

- 위치: `/` 모바일
- 문제: 잠금 상태에서도 full-page가 매우 길게 잡히고, 잠금 해제 후 모바일 홈은 모든 섹션이 한 페이지에 이어져 지나치게 길다.
- 면접관이 받을 인상: "모바일 UX 검수를 제대로 안 했다."
- 심각도: High
- 수정 방향: 모바일에서는 잠금 화면을 제거하고, 섹션별 라우트 또는 탭형 목차로 분리한다.
- 바로 적용할 문구 또는 디자인 수정안: 모바일 첫 화면은 `소개 / 대표 프로젝트 / 이력서 / 연락처` 4개 CTA만 남긴다.

## 루트 OS 창

### About, Skills, Resume 창

- 위치: `/`의 About, Skills, Resume 창
- 문제: 창 내부 콘텐츠가 화면 아래로 잘리거나 스크롤을 전제로 한다. Dock과 창 조작이 콘텐츠보다 앞선다.
- 면접관이 받을 인상: "포트폴리오가 아니라 UI 장난감 같다."
- 심각도: High
- 수정 방향: OS 컨셉은 유지하더라도 기본 정보는 일반 웹 레이아웃으로 읽히게 한다.
- 바로 적용할 문구 또는 디자인 수정안: 데스크톱 기본 레이아웃을 `좌측 프로필 + 중앙 대표 프로젝트 + 우측 증빙 링크` 대시보드로 변경한다.

### Case Studies 창

- 위치: `/`의 Case Studies 창
- 문제: `200 GET`, `500 PATCH` 같은 API 로그형 UI가 프로젝트 설명을 가린다. 실제 API가 아니라 장식처럼 보인다.
- 면접관이 받을 인상: "기술적으로 있어 보이려는 연출인가?"
- 심각도: High
- 수정 방향: 가짜 로그 UI 대신 실제 산출물 링크, GitHub, 화면 캡처, 발표자료를 보여준다.
- 바로 적용할 문구 또는 디자인 수정안: `증빙: 요구사항정의서 v1.7 / 화면명세서 / GitHub / 시연 영상`

### Portfolio AI 창

- 위치: `/`의 Portfolio AI 창
- 문제: `로컬 모델 연결 전` 상태를 기능처럼 노출한다. 작동하지 않는 기능은 신뢰를 깎는다.
- 면접관이 받을 인상: "미완성 기능을 배포했다."
- 심각도: Critical

- 바로 적용할 문구 또는 디자인 수정안: `자주 받는 질문 4개` 정적 섹션으로 변경하고 AI 입력창은 제거한다.

### Contact 창

- 위치: `/`의 Contact 창
