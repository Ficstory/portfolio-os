# 부산이음길 초기 기획과 인터뷰 기반 MVP 선정

작업일: 2026-09-14. 기존 `/PM/`의 부산이음길 카드·상세·기여 요약을 수정했다.

## 사용자 확인 내용

사용자는 부산이음길을 처음부터 기획했으며, 기획을 구체화하기 위해 함세상장애인자립센터를 섭외해 미팅·인터뷰를 진행하고 MVP를 선정했다고 직접 확인했다. 이전의 ‘기획 보완’이라는 역할 요약은 초기 기획과 MVP 선정을 충분히 표현하지 못했으므로 이번 확인 내용으로 대체한다. 기존 지도·마커 고정·프론트엔드 개발과 추가 설정·제보 작업은 유지한다.

## 확인한 기록

원본 프로젝트 경로: `SSAFY/프로젝트/4. 자율pjt/S14P31E102`.

- `Docs/기획/archive/research/2026-04-10_함세상_장애인자립생활센터_인터뷰_결과.md`: 2026-04-10 인터뷰 기록. 기관명은 ‘함세상 장애인자립생활센터’. 여러 경로 선택지와 이동 장벽 정보, 이동 수단별 조건 차이, 화장실·충전기·건물 진입 등 주변 접근성 정보를 핵심 요구로 정리했다.
- `Docs/PRD/2026-04-09_부산이음길_PRD.md` 및 `Docs/기획/2026-04-10 최종_프로젝트_기획서.md`: 4월 28일 개정 기준 사용자 유형 온보딩, 접근성 필터·시설 상세, 경로 비교·상세·길안내가 MVP 범위에 포함돼 있다.

공개 설명은 위 자료와 사용자 설명을 바탕으로 인터뷰 요구와 MVP의 핵심 방향을 연결한다. 모든 인터뷰 요청이 구현됐다고 쓰거나, 세 가지 요약이 MVP 전체 목록이라고 제시하지 않는다. 인터뷰 인원·발언 원문·개인정보·협약·안전성 검증·성능 수치를 추가하지 않는다. 초기 기획의 개인 기여는 사용자 확인 내용이고, 인터뷰 결과 문서는 팀 기록이다.

사진은 수정 없이 `public/pm-improved/evidence/busan-mvp-meeting.png`에 추가했다. 추출본과 공개 자산 SHA-256은 모두 `9b9dfa91117d7cb20213bcc548bd7a669d61767d435f506936ea4e4c784f87a4`다. 파생 투명 컷아웃 이미지 `image44.png`는 사용하지 않았다.

## 수정 파일과 검증

- `src/components/pm-improved/content.ts`: 부산 카드·역할·행동·결과·역량·경험 연결 문구.
- `PmVisuals.tsx`: 초기 기획·인터뷰·MVP 선정과 지도 개발을 나란히 보여주는 대표 기여.
- `PmSupportingCase.tsx`: 초기 기획과 인터뷰에서 MVP로 이어진 설명, 미팅 사진, 주요 산출물·역할 분담·배움.
- `visuals.module.css`: 원본 비율을 유지하는 미팅 사진 표시.
- 위 컴포넌트 파일명은 모두 `src/components/pm-improved/` 기준이다.

변경 TypeScript/TSX의 ESLint 성공. `npm run build`와 내장 TypeScript 검사 성공, 정적 페이지 25개 생성. 이번 정적 콘텐츠 수정에 새 단위 테스트를 추가하지 않았다.

원본 source/public/config 168개 해시와 최근 Experience·메인 Hero·이력서·헤더 8개 파일 해시가 동일하다. `scripts/check-pm-improved.mjs`는 13개 경로, 로컬 대상 65개, 대문자 유지 리다이렉트 5개, RSC 요청 4개를 통과했다. [HTTP 기록](pm-improved/busan-planning-http-checks.json).

Chrome에서 메인과 부산 상세를 1440·768·390·360px, 총 8개 조합으로 확인했다. 초기 기획·기관명·MVP 문구 표시, 기존 축소 문구 제거, 가로 넘침 없음, 상세 새로고침, 원본 1920×1080 사진 로드를 확인했다. 데스크톱과 모바일의 사진·캡션·MVP 설명을 직접 시각 확인했고 콘솔 경고·오류는 0개였다. [브라우저 기록](pm-improved/busan-planning-browser-checks.json).

로컬 프로덕션 반영까지 완료했으며 커밋·push·공개 배포는 수행하지 않았다.
