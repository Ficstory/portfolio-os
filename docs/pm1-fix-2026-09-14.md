### 1. 키보드 포커스 가림: 기능 오류 수정

기존 1440×900 PROJECTS → Tab → Tab 경로에서 선택 버튼을 다음 카드가 덮는 문제를 재현한 뒤 수정했다. 카드 자체의 `:has(:focus-visible)` 상태에서 쌓임 순서를 높였다. 버튼 테두리만 변경하거나 양의 tabindex로 탐색 순서를 바꾸지 않았다.

세 카드의 Tab·Shift+Tab, Enter 열기, Escape 닫기, 원래 버튼으로의 포커스 복귀를 실제 브라우저에서 확인했다. 버튼 중심선의 상하좌우 지점에 대해 실제 화면의 최상위 요소를 검사했고 선택 버튼과 일치했다. 상세의 첫 X 버튼↔마지막 닫기 버튼 순환, 중간 출처 링크 탐색도 확인했다. 역방향 탐색 시 카드 높이나 문서 위치가 바뀌지 않았고, 필요한 경우 브라우저가 버튼까지 스크롤했다.

마우스로 전환하면 포커스 카드의 추가 쌓임 순서가 해제된다. 1440×900에서 기존 sticky 위치 28px·56px와 축소 효과가 유지됐다. 390×844와 1024×600에서는 세 카드 모두 일반 세로 흐름으로 전환됐다. 상세창은 네이티브 최상위 레이어에 열려 카드의 transform·overflow에 잘리지 않는다.

카드 요약을 그대로 반복하던 상세 문단을 제거했다. 상세는 구체적인 문제·판단·변경·확인 범위와 가까운 출처 링크를 제공한다. 자료를 바탕으로 사이트에서 재구성한 요약임을 표시했다. 원본 캡처처럼 만든 이미지나 새로운 성과 수치는 추가하지 않았다.

전역 스타일·의존성·기존 페이지 코드는 이번 보완에서 수정하지 않았다. 빌드가 갱신하는 next-env.d.ts는 자동 생성 파일이다. 기존 PM1 구현과 sitemap 변경은 이전 작업의 미배포 상태 그대로 함께 검토해야 한다.

운영 반영 시 기존 배포 프로젝트에서 PM1 경로·컴포넌트·에셋과 기존 공개 근거 파일 7개가 모두 포함되는지 확인해야 한다. 새 상세가 참조하는 일부 근거 파일은 사용자 작업 트리에서 추가된 파일이므로 PM1 컴포넌트만 배포하면 누락될 수 있다. 릴리스 파일 목록·해시는 별도 `release-manifest.json`에 기록했다. 전체 작업 트리를 일괄 배포하는 대신 이 범위를 기준으로 검토할 수 있다.

현재 미리보기는 준비됐으며, 남은 실행은 사용자의 운영 배포 승인과 기존 배포 경로를 통한 반영이다.
