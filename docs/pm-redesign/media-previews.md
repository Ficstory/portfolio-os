## 구현과 재생 정책

`PmVideoPreview.tsx`가 네 프로젝트의 영상 재생을 맡는다. 원본을 변경하지 않고 `public/pm/previews/`에 H.264 MP4, WebP 포스터를 별도로 만들었다. 영상은 모두 24fps, 오디오 트랙 없음, faststart 적용이다.

- AEKKIM: 270,747바이트.
- 부산이음길: 270,808바이트.
- 웃지마게임: 260,537바이트.
- Play Pick: 871,433바이트. 포스터 72,348바이트. 1280×960 보관용 영상은 `play-pick-demo/play-pick-onboarding.mp4`에 별도로 저장했다.
- 영상 합계 1,673,525바이트. 포스터 4개는 합계 143,960바이트.

`preload="none"`으로 시작한다. 화면에 보이고 탭이 활성 상태일 때 무음으로 반복하며, 화면 밖이나 숨겨진 탭에서는 정지한다. 사용자가 일시정지한 영상은 다시 스크롤해도 자동 재생하지 않는다. `prefers-reduced-motion`과 `saveData` 환경에서는 자동 재생하지 않고 사용자가 재생 버튼을 누를 수 있게 한다. 영상 로딩 실패 시 포스터와 원본 미리보기 링크를 제공한다.

영상 내부에는 전체 사례로 이동하는 링크를 씌우지 않는다. 재생 버튼을 누를 때 의도치 않게 상세로 이동하는 중첩 인터랙션을 피하고, 제목과 ‘사례 읽기’는 기존 상세 링크를 유지한다. 키보드 조작 가능한 재생·일시정지, 크게 보기, 화면 설명을 제공한다.

웃지마게임의 홈 대표 비주얼은 녹화로 변경했다. 기존 Q9 설문 그래프와 인원수는 상세 페이지에 유지했다. 다른 프로젝트와 루트·다른 직무 트랙은 변경하지 않았다.

영상은 FFmpeg로 구간 추출·크롭·축소·무음 인코딩했다. 애낌은 기존 앱을 데모 데이터로 실행해 Android 화면을 연속 녹화한 뒤 축소했으며, 화면 합성이나 배속 변경을 하지 않았다. 애낌 캡처 6장과 재현 패치는 `aekkim-demo/`, 큰 원본 영상과 APK는 무시되는 `.codex_tmp/aekkim-demo-output/`에 있다.
