# 요구사항 명세서

## 1. 프로젝트 개요

이 프로젝트는 개인 포트폴리오를 일반 랜딩페이지가 아니라 잠금화면과 데스크톱 UI를 가진 웹앱처럼 경험하게 만드는 FE 중심 포트폴리오 사이트다. 방문자는 첫 화면에서 감성적인 잠금화면 랜딩을 보고, 입장 동작 이후 바탕화면, 폴더, 창, Dock, Menu Bar를 통해 프로젝트와 경험을 탐색한다.

## 2. 목표

- 포트폴리오를 단순 자기소개 페이지가 아니라 탐색 가능한 개인 작업 공간처럼 보여준다.
- 대표 프로젝트 3개를 깊이 있게 보여준다.
- FE 개발자의 기획, UI 구현, 문제 해결, 콘텐츠 구조화 역량을 동시에 드러낸다.
- 정적 사이트만으로 빠르고 안정적으로 배포한다.

## 3. 사용자

- 채용 담당자: 짧은 시간 안에 지원자의 대표 프로젝트와 기술 역량을 확인한다.
- 개발 리드 또는 현업 개발자: 구현 방식, 트러블슈팅, 기술 선택 이유를 확인한다.
- 협업자 또는 외부 방문자: 이력서, 연락처, 프로젝트 링크에 빠르게 접근한다.

## 4. 범위

### 4.1 MVP 포함 범위

- 잠금화면형 랜딩 화면
- 포트폴리오 입장 또는 unlock 전환
- 데스크톱형 메인 화면
- 바탕화면 폴더 아이콘
- Dock
- Menu Bar
- 창 열기, 닫기, 이동, 활성화
- About Me 폴더
- Projects 폴더와 대표 프로젝트 3개
- Skills 폴더
- Resume 폴더: 웹 요약본과 PDF 다운로드
- Contact 폴더
- 다크/라이트 테마
- 모바일 반응형 대응
- 기본 SEO와 Open Graph 메타데이터

### 4.2 MVP 제외 범위

- 블로그와 노트
- 관리자 페이지
- 댓글, 방명록, 좋아요
- 서버 저장형 연락처 폼
- 외부 CMS
- 사용자 계정과 인증
- 실제 파일 시스템 연동

| REQ-016 | 키보드 탐색과 포커스 이동이 가능해야 한다. |
| REQ-017 | 애니메이션은 사용자의 reduced motion 설정을 존중해야 한다. |
| REQ-018 | SEO 메타데이터와 Open Graph 이미지를 제공해야 한다. |
| REQ-019 | 콘텐츠는 정적 데이터와 Markdown 또는 MDX 기반으로 관리한다. |
| REQ-020 | MVP는 BE 없이 정적 사이트로 배포 가능해야 한다. |

## 9. BE 필요 여부

MVP에서는 BE가 필요하지 않다. 모든 콘텐츠는 정적 파일과 빌드 타임 데이터로 제공할 수 있고, 연락은 외부 링크와 이메일 링크로 처리할 수 있다.

### 백엔드 개발자에게 전달할 작업사항

MVP에서는 전달할 BE 작업이 없다. 다만 2차 이후 서버 저장형 연락처 폼, 방문자 통계, 관리자 페이지, CMS, 방명록을 추가할 경우 다음 작업을 백엔드 개발자에게 전달한다.

- 연락처 폼 API, 메일 발송, 스팸 방지, 요청 제한
- 방문 이벤트 저장 API와 관리자 조회 기능
- 콘텐츠 관리 API, 인증, 이미지 업로드
- 방명록 또는 댓글 저장, 신고, 삭제, moderation

## 10. 수용 기준

- 방문자는 첫 화면에서 잠금화면형 랜딩을 인지할 수 있다.
- 입장 후 데스크톱형 포트폴리오 화면으로 자연스럽게 전환된다.
- 대표 프로젝트 3개를 같은 구조로 탐색할 수 있다.
- 이력서 PDF 다운로드와 웹 요약본 접근이 모두 가능하다.
- 모바일에서도 About, Projects, Skills, Resume, Contact에 접근할 수 있다.
- 문서와 코드 구현은 FE 범위 안에서 완결된다.
