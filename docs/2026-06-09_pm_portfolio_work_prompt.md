# PM 포트폴리오 개편 작업 프롬프트

너는 시니어 프론트엔드 엔지니어이자 PM 포트폴리오 정보설계 전문가다.

먼저 아래 계획서를 읽고, 그 문서의 적용 범위와 섹션 설계를 기준으로 작업한다.

- `docs/2026-06-09_acctual_pm_portfolio_application_plan.md`

작업 목표:

- Acctual 레퍼런스의 전환형 정보 설계와 설득 흐름을 참고해 이 사이트의 **PM 포트폴리오(`/pm`)만** 개선한다.
- Acctual의 문구, 이미지, 브랜드, 인보이스/결제 콘텐츠는 복제하지 않는다.
- 계획서에 정리된 PM 전용 구조를 바탕으로, PM 채용자가 문제 정의, 요구사항 정리, MVP 범위 조율, 협업 방식, 산출물, 실행 근거를 빠르게 검증할 수 있게 만든다.

작업 제한:

- `/pm` 외의 `/`, `/public-digital`, `/policy`, `/assembly` 페이지는 의도적으로 바꾸지 않는다.
- 공용 트랙 컴포넌트를 전역 수정하지 않는다.
- 가능하면 `src/components/tracks/pm/` 하위에 PM 전용 컴포넌트와 데이터를 만들고, `src/app/pm/page.tsx`에서 PM 전용 페이지를 렌더링한다.
- 실제 검증되지 않은 성과 수치, 가짜 후기, 허위 문서 링크를 만들지 않는다.
- 기존 변경사항을 되돌리지 않는다.

구현 후 확인:

- `/pm` 페이지가 계획서의 PM 전용 섹션 구조를 따른다.
- 다른 직무 트랙의 화면과 카피가 의도치 않게 바뀌지 않았다.
- 모바일/데스크톱에서 텍스트, 버튼, 카드, 표가 넘치지 않는다.
- 가능한 검증 명령을 실행하고 결과를 보고한다.
