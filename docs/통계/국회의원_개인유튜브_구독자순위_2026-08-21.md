## 집계 방법과 유의사항

1. 국회 SNS 목록 파일의 의원 유튜브 등록 191개를 전수 확인했다.
2. 기존 링크가 오래되어 열리지 않는 36개 중 33개는 최신 공식 채널로 보정했다. 최신 공식 채널을 확정하지 못한 3개는 순위 판단에서 제외했다.
3. 국회 SNS 목록에 빠져 있지만 현직 의원인 송영길 채널은 별도로 확인해 포함했다.
4. 정당·언론사·팬 채널은 제외하고, 의원 본인이 운영하는 채널만 대상으로 했다.
5. 구독자 수는 실시간으로 바뀌는 지표이므로, 본 문서의 수치는 2026-08-21 확인 시점의 표시치다.

## 포트폴리오 활용 메모

- **정청래·김병주·박선원**: 현장 쇼츠와 라이브로 지지층과 직접 소통하는 형태.
- **주진우**: 이슈를 해설하는 방송형 콘텐츠.
- **박주민·용혜인**: 의정 활동과 정책을 설명하는 정보형 콘텐츠.
