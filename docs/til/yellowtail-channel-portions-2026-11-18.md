# 이마트와 트레이더스 방어 후토마키의 양과 가격

조사·개정일 2026-11-18. **현행 기획은 본매장 6점(가운데 5 + 꼬다리 1)·방어 90g=끝살 45g+필렛 45g·본체 234g·별첨 포함 241g, 정상 13,980원·20% 행사 11,184원이다. 트레이더스는 12점(가운데 10 + 꼬다리 2)·방어 180g=끝살 90g+필렛 90g·본체 468g·별첨 포함 482g, 정상 19,980원·20% 행사 15,984원을 제안한다.** 방어량·반반 배합·입수와 할인율은 사용자 요청을 반영했다. 원가·작업시간·판매가는 검증 전 기획값이다. 하루 10팩·9팩 판매와 초도 6팩·5팩 판매는 한 팩 폐기의 부담을 확인할 시나리오이며 실제 판매량 예측이 아니다.

## 원래 방어량과 반반 배합으로 복원한 한 팩

| 설계 항목 | 이마트 본매장 | 트레이더스 비교안 |
|---|---:|---:|
| 조각 배분 | 6점 = 가운데 5 + 꼬다리 1 | 12점 = 가운데 10 + 꼬다리 2 |
| 방어 끝살 + 필렛 순살 | 45g + 45g = 90g | 90g + 90g = 180g |
| 조미밥 / 배액 묵은지 / 오이 / 김 | 120 / 10 / 12 / 2g | 240 / 20 / 24 / 4g |
| 본체 / 별첨 포함 식품 총량 | 234g / 241g | 468g / 482g |
| 간장 5g·고추냉이 2g | 각 1봉 | 각 2봉 |
| 정상 / 20% 행사 제안가 | 13,980 / 11,184원 | 19,980 / 15,984원 |
| 정상 / 행사 100g당(별첨 포함) | 5,801 / 4,641원 | 4,145 / 3,316원 |

본매장 방어를 135g으로 증량했던 안은 철회하고 원래 90g으로 돌렸다. 끝살과 필렛 순살은 각각 45g이다. 방어 비중은 본체의 약 38.5%, 현행 한 점은 평균 본체 39g·방어 15g이다. 별첨은 본매장 7g·트레이더스 14g이다. 과거 6점·351g 안의 본체 점당 58.5g보다 약 33.3% 가벼워졌지만 지름·입안 부담·베어 먹기 편함은 현물로 검증하지 않았다.

본매장 정상 13,980원은 참치·연어 6점 표시가보다 820원(약 5.5%) 낮다. 방어 행사는 13,980 × 0.8 = 11,184원으로 정확히 20%, 2,796원 할인이다. 참치·연어 제보 행사가 11,840원보다 656원 낮다. 트레이더스 방어도 19,980 × 0.8 = 15,984원으로 정확히 20%, 3,996원 할인이다. 참치 비교품보다 정상 1,000원(약 4.8%)·행사 2,996원(약 15.8%) 낮다. 본매장 241g 두 팩의 정상 합계 27,960원과 비교하면 공유용 482g 한 팩은 7,980원(약 28.5%) 낮다. 동일 배합의 공유용 가격 차이이며 비교품 중량·고객 지불의향·판매량은 미검증이다.

배합 두 배를 긴 한 줄로 말고 반으로 나눈다. 각 반 줄을 가운데 5점과 자연 끝 1점으로 잘라 본매장에서는 반 줄씩 두 팩, 트레이더스에서는 두 반 줄을 한 팩에 담는다. 본매장은 6점 한 줄, 트레이더스는 6점씩 두 줄이며 양념 공간은 짧은 면으로 모은다. 긴 롤 성형·이음매·트레이 크기·꼬다리 속 빠짐은 현물 시험 전이다. 6점·12점은 기획 규격이지 제조 실측 결과가 아니다.
