## 보존과 검증 기록

기존 원본 168개 파일 기준선은 이전 감사의 manifest를 계속 사용한다. 이번 수정 전 헤더, 이력서 경로 설정, PDF와 Word 자산 해시는 `pm-improved/copy-followup-preserved.json`에 별도로 남겼다. 수정 전 프로덕션 메인과 부산 상세의 렌더링 텍스트는 `pm-improved/copy-before-dom.json`에 있다.

작업 분담의 실제 turn_context는 Sol/high(공통 서비스 소개·카드와 상세 Hero), Sol/high(부산·웃지마게임·도식), Terra/medium(애낌·Play Pick 상세)으로 확인했다. 전체 편집 판단·근거 확인·최종 검증은 Astra에서 수행한다.

### 최종 실행 결과

- `npm run lint`: 성공, 오류 0개. 기존 `electioncommon.js`, `scripts/collect-instagram-public.mjs`에서 경고 92개. 변경 컴포넌트의 별도 lint도 성공했다.
- 기존 `src`의 `*.test.mjs`를 `node --test`로 실행: 74개 통과, 실패 0개.
- `npm run build`: 최종 성공. Next.js의 TypeScript 검사 통과, 정적 페이지 25개 생성. 첫 통합 빌드에서 새 데이터 구조에 남은 `principle.related` 참조를 발견해 제거한 뒤 다시 빌드했다.
- 빌드가 갱신하는 `next-env.d.ts`는 작업 전 저장한 사용자 변경 바이트로 복원했다. 원본 source/public/config 168개 SHA-256 일치. 헤더·이력서 경로 설정·PDF·Word 자산의 별도 4개 해시도 일치.
- `node scripts/check-pm-improved.mjs http://127.0.0.1:3211 docs/pm-improved/copy-http-checks.json`: 통과. 13개 경로, 로컬 링크·자산 64개, 슬래시·query 리다이렉트 5개, RSC 요청 4개, canonical·OG·내부 경로 noindex, 상세 절·역할 순서 확인. 알려지지 않은 slug와 잘못된 대소문자는 404.
- `node scripts/check-pm-links.mjs http://127.0.0.1:3211`: 기존 14개 페이지와 로컬 대상 46개 통과.
- 프로덕션 서버의 실제 Chrome 화면: 1440·768·390·360px × 5페이지, 총 20개 조합 확인. 가로 넘침·깨진 로드 이미지·금지된 편집 문구 없음. 상세 4개 직접 접근·새로고침 통과.
- 시연 4개 재생·일시정지 통과, `readyState: 4`, 미디어 오류 없음. 메인 → 애낌 → 다음 부산 프로젝트 및 상세 → 메인 이동에서 `/PM/` 유지. 수집된 브라우저 콘솔 경고·오류 0개.
- 부산 실제 지도 이미지의 원본 크기 720×1560 로드와 모바일 표시를 확인했다. 대표 기여 두 블록은 데스크톱에서 동일 너비·높이이며 모바일에서는 같은 스타일로 세로 배치된다. 추가 도식은 지도 개발 뒤에 있다.

HTTP 결과는 [copy-http-checks.json](pm-improved/copy-http-checks.json), 화면·이동·미디어 결과는 [copy-browser-checks.json](pm-improved/copy-browser-checks.json)에 있다. 이번 화면 캡처는 `pm-improved/copy-*.png`에 저장했다. 이 문서와 검증 기록은 공개 라우트에 연결하지 않았다.

이번 검증은 포트폴리오 웹 화면과 링크에 대한 것이다. 실제 휴대전화·Safari·채용 담당자 사용성 평가와 원본 Android 앱의 재실행은 수행하지 않았다.
