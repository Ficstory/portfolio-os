## 오늘 배운 것

AI로 문서를 만들 때 원하는 결과의 기준을 먼저 정리하는 것이 중요하다고 느꼈다. 이번에는 보고서 레퍼런스와 브랜드 색상, 서체를 정하고 내용에 대한 프롬프트를 다듬은 뒤 HTML → PDF 방식으로 작업했다. 결과물에 매우 만족했고, 다음 보고서도 이 흐름으로 만들어 보고 싶다.

오늘 과제는 어제 만든 카드뉴스, 포스터, 웹포스터 등 홍보물을 종합해 실제 홍보에 들어가기 전 최종 홍보기획서를 작성하는 것이었다. 기존 콘셉트·타깃·핵심 가치를 유지하면서 홍보물의 제작 의도, 채널별 집행 계획, 오픈 전·당일·후 실행 체크리스트까지 담아야 했다.

## 직접 시도한 것

주어진 시간은 1시간 반이었고 사용 도구는 제미나이로 제한되어 있었다. 하지만 이전에 제미나이로 문서 작업을 했을 때 내 자체 평가가 매우 낮았고, 이번에도 원하는 수준의 결과를 낼 자신이 없었다. 그래서 이번에는 지정된 도구 대신 GPT를 사용했다.

먼저 카드뉴스 6장, 포스터 2종, 짧은 영상, 팀에서 만든 기획서를 바탕으로 보고서의 내용과 순서를 정리하도록 요청했다. 최종 산출물은 A4 세로 PDF로 정하고, HTML/CSS 초안에서 인쇄 형태를 잡은 뒤 PDF로 변환하는 제작 흐름을 선택했다.

미리캔버스에서 보고서 레퍼런스 8장을 내려받아 전달했다. 넓은 여백, 가는 글자와 굵은 글자를 조합한 제목, 얇은 구분선, 원형 번호, 부드러운 곡선 같은 편집 요소를 참고하도록 했다. 레퍼런스의 파란색을 그대로 쓰는 대신 이마트 브랜드 색상을 적용하고, 새로 작성하는 텍스트의 서체는 Pretendard로 지정했다.

프롬프트는 단계적으로 구체화했다. 처음에는 작업계획과 구성 순서를 요청했고, 이후 A4 출력 방식과 레퍼런스, 브랜드 색상, 서체를 더했다. 최종 프롬프트에는 약 16쪽의 페이지 구성과 홍보물별 설명 순서, 미확정 정보의 처리 기준, PDF 검수 항목까지 포함했다.

특히 카드뉴스·포스터·영상은 실제 이미지와 장면을 중심으로 설명하고, 제작 의도에서 채널·노출 위치·행동 요청·확인할 성과까지 연결하도록 했다. 기존 기획과 다른 내용을 섞거나 확인되지 않은 가격·혜택·성과 수치를 만들어 넣지 않도록 기준도 명시했다.

이렇게 정리한 프롬프트로 GPT 아스트라 모델에서 HTML → PDF 워크플로우를 실행했다. 이번 결과물은 내 기준에서 매우 만족스러웠다.

당신은 기업 보고서의 콘텐츠 기획과 편집 디자인, HTML/CSS 기반 PDF 제작을 담당하는 디자이너다.

제공한 보고서 레퍼런스 이미지 1.png~8.png와 기존 작업계획을 바탕으로, 「이마트 신촌점 K-Palette Zone 오픈 홍보기획서」를 제작하라. 기존 기획의 콘셉트·타깃·핵심 가치를 유지하면서 실제 홍보물과 실행 계획을 설득력 있게 설명하는 A4 보고서를 완성하는 것이 목표다.

### 1. 기본 정보와 산출물

- 제목: 이마트 신촌점 K-Palette Zone 오픈 홍보기획서

- 분량: 약 16쪽. 이미지와 본문의 가독성을 위해 필요한 경우 소폭 늘릴 수 있다.
- 제작 방식: HTML/CSS 초안 → A4 인쇄 미리보기 → PDF 출력 → 전 페이지 검수
- 최종 제출물: 이재호_K-Palette_Zone_오픈_홍보기획서.pdf
- 수정 가능한 HTML/CSS 원본과 사용 자산도 함께 정리한다.

### 2. 레퍼런스 해석

첨부 이미지의 편집 구조와 시각적 분위기를 참고하되 보고서 내용에 맞게 재구성하라.

유지할 특징은 다음과 같다.

- 넓은 여백과 일관된 왼쪽 정렬
- 가는 글자와 굵은 핵심 단어를 조합한 큰 제목
- 페이지 상단의 얇은 띠와 절제된 구분선
- 옅은 배경색으로 구분되는 제목 영역
- 큰 번호를 활용한 목차와 원형 번호를 활용한 목록
- 하단이나 모서리에 흐르는 부드러운 중첩 곡선
- 일정한 위치의 페이지 번호
- 이미지와 설명이 명확하게 구분되는 단정한 보고서 구성

레퍼런스에 들어 있는 경찰청 문구, 예시 이름, 이메일, 안내 문장, 임의의 그래프 수치와 워터마크는 사용하지 않는다. 레퍼런스 이미지를 페이지 전체 배경으로 붙이지 말고 레이아웃과 도형을 새로 구현한다.

### 3. 색상 적용

이마트 공식 CI 원본의 노랑과 회색을 브랜드 색상 기준으로 사용한다. 정확한 색상값은 공식 자산에서 확인하며, 임의의 HEX 값을 공식 브랜드 규정으로 단정하지 않는다.

보고서의 색상 역할은 다음과 같이 정한다.

- 이마트 노랑: 강조 면, 번호 배경, 주요 구분 요소
- 브랜드 회색과 짙은 차콜: 제목, 본문, 선
- 흰색: 본문 페이지의 기본 바탕
- 옅은 크림색: 제목 영역, 표 헤더, 설명 박스
- 연한 회색: 보조 정보와 구획

레퍼런스의 파란색 곡선은 노랑·크림 계열의 은은한 곡선으로 바꾼다. 곡선은 표지·목차·마지막 페이지에 집중하고, 본문에서는 사진이나 글자를 방해하지 않도록 제한적으로 사용한다.

흰 배경에 노란색으로 작은 글자를 쓰지 않는다. 노란 면 위의 글자는 짙은 차콜로 처리한다. 강한 그림자, 과도한 둥근 카드, 불필요한 장식과 입체 효과는 사용하지 않는다.

브랜드 색상은 보고서의 편집 요소에 적용한다. 제공된 카드뉴스와 포스터 자체의 색상·내용은 임의로 변경하지 않는다.

### 4. 서체와 편집 규칙

보고서에서 새로 작성하는 제목·본문·표·캡션·페이지 번호는 모두 Pretendard를 사용한다. 기존 홍보물 이미지 안에 포함된 글자는 원본을 유지한다.

- 표지 제목: 약 40~48pt
- 페이지 제목: 약 24~30pt
- 소제목: 약 14~16pt
- 본문: 약 10.5~11.5pt
- 캡션과 출처: 약 9~10pt
- 본문 행간: 약 1.5~1.65
- 기본 여백: 좌우 약 18~20mm, 상하 약 18mm

큰 제목은 Light 또는 Regular와 SemiBold 또는 Bold를 조합한다. 본문은 Regular 이상으로 설정해 인쇄 가독성을 확보한다.

Pretendard를 실제로 로드하고 PDF에서도 적용됐는지 확인한다. 글꼴 로딩에 실패한 상태에서 대체 서체로 출력하고 완료 처리하지 않는다.

페이지마다 정렬선과 간격을 통일한다. 내용이 넘치면 글자를 무리하게 줄이거나 숨기지 말고 문장을 정리하거나 페이지를 추가한다.

### 5. 내용의 기준

기존 9쪽 최종 기획서를 콘셉트의 우선 기준으로 사용한다.

반드시 유지할 내용은 다음과 같다.

- 공간명: 이마트 신촌점 K-Palette Zone
- 콘셉트: 진짜 한국인이 사랑하는 리얼 픽
- 타깃: SNS에서 K-상품을 발견하고 제한된 여행 시간 안에 쇼핑하려는 외국인 관광객
- 대표 페르소나: K-POP 여행과 귀국 전 식료품·선물 구매를 하는 중국인 관광객
- 핵심 가치: 찾기 쉽고, 고르기 쉽고, 이해하기 쉬운 쇼핑
- 핵심 해결책: 바닥 안내선·AR, SNS 기반 인기상품 큐레이션, NFC 다국어 정보
- 고객 경험: FIND → PICK → CHECK → BUY → SHARE

기존 기획의 샤오홍슈 유입 경로를 유지하면서 인스타그램 홍보물의 역할을 연결한다.

다른 문서의 공간명이나 QR·NFC 방식을 임의로 혼합하지 않는다. 기존 기획의 목표와 실제 달성 실적을 구분하고, 확인되지 않은 가격·혜택·서비스·날짜·성과 수치를 만들어 넣지 않는다.

### 6. 실제 홍보물 활용

홍보물은 카드뉴스·포스터·인스타그램 영상의 3종으로 구분한다.

카드뉴스 6장은 전체 흐름을 보여준 뒤 장별로 확대해 설명한다. 관심 유도 → 불편 공감 → 길찾기 → 추천 상품 → 다국어 정보 → 방문 안내의 흐름을 드러낸다.

포스터 2종은 각각 충분한 크기로 배치한다. 상품·가격을 강조한 포스터와 영어·K-컬처 표현을 활용한 포스터가 어떤 상황과 접점에 적합한지 설명한다.

영상은 제공된 약 51초 세로형 원본에서 실제 장면을 추출한다. 스틸컷 6개 안팎에 타임코드와 장면 의도를 붙여 쇼핑의 어려움이 해결되는 과정을 설명한다. 영상 재생은 PDF 내장 재생에 의존하지 않는다. 유효한 공개 링크가 준비된 경우에만 재생 링크나 QR을 삽입한다.

각 홍보물의 설명 순서는 다음과 같이 통일한다.

실제 이미지 → 타깃의 상황 → 제작 의도 → 핵심 메시지 → 채널과 노출 위치 → 행동 요청 → 확인할 성과

제작 의도를 원본에서 해석한 경우에는 확인되지 않은 제작자의 과거 의사결정처럼 단정하지 않는다.

이미지는 원본 비율을 유지하고 중요한 문구를 자르지 않는다. 낮은 해상도의 자료는 고화질 원본 확보를 우선하며, 단순 확대를 화질 개선으로 간주하지 않는다.

### 7. 권장 페이지 구성

1쪽: 표지
큰 제목과 넉넉한 여백, 은은한 노랑 곡선으로 구성한다. 기관과 보고자를 명확히 표기한다.

2쪽: 목차와 보고 개요
레퍼런스의 2열 목차 구조를 활용한다. 기획 배경, 홍보 전략, 제작물, 채널 계획, 실행 체크리스트, 성과 측정의 여섯 항목으로 정리한다.

3쪽: 기존 기획의 계승
콘셉트·타깃·핵심 가치와 홍보 메시지의 관계를 보여준다.

4쪽: 홍보 전략
영상의 관심 유도, 카드뉴스의 이해·저장, 포스터의 현장 방문 역할을 연결한다.

5~7쪽: 카드뉴스
전체 6장 흐름과 장별 이미지·설명을 배치한다.

8~9쪽: 포스터
포스터별 큰 이미지와 제작 의도·배치 위치·행동 요청을 설명한다.

10~11쪽: 영상
실제 스틸컷, 타임코드, 장면별 메시지와 게시 방향을 설명한다.

12쪽: 채널별 집행 계획
채널·대상·시점·콘텐츠·행동 요청·담당 역할·측정 지표를 정리한다.

13쪽: 오픈 전 체크리스트
D-14~D-1의 정보 확인, 소재 검수, 사전 공개, 설치 준비를 정리한다.

14쪽: 오픈 당일과 오픈 후 체크리스트
게시·현장 점검·문의 대응·오류 수정·성과 검토를 정리한다.

15쪽: 성과 측정과 운영 계획
측정 가능한 KPI, 집계 방법, 예산 항목, 담당 역할과 개선 기준을 설명한다.

16쪽: 실행 요약과 출처
핵심 실행 사항과 자료 출처를 정리하고 보고자·기관 표기로 마무리한다. 레퍼런스 마지막 페이지의 절제된 구성을 활용한다.

별도의 PART 구분 페이지만 반복해 분량을 늘리지 않는다. 필요한 구분은 본문 제목 영역에서 처리한다.

### 8. 실행 계획과 데이터 표현

오픈 날짜가 확정되지 않았으면 D0를 기준으로 상대 일정을 사용한다.

체크리스트에는 시점, 할 일, 담당 역할, 완료 여부, 증빙, 문제 발생 시 조치를 포함한다. 확인되지 않은 담당자 이름이나 운영 계정을 만들지 않는다.

가격·2+1·공항 배송·Tax Free·실시간 Top 100·AR·NFC 제공 범위는 실제 운영 조건 확인 항목으로 구분한다.

조회·저장·공유·링크 유입과 실제 매장 방문·구매는 별도로 설명한다. 근거 없는 수치로 막대그래프나 원그래프를 만들지 않는다. 수치가 없으면 채널 비교표, 고객 행동 흐름, 일정표를 사용한다.

### 9. PDF 제작과 최종 검수

HTML/CSS 단계부터 A4 인쇄 크기와 페이지 나눔을 명시한다. 곡선과 간단한 도형은 CSS 또는 SVG로 구현한다.

글꼴과 이미지 로딩이 완료된 후 배경색을 포함해 PDF로 출력한다. 브라우저가 자동으로 붙이는 날짜·URL 머리말은 제외하고 문서 자체의 쪽번호를 사용한다.

최종 PDF는 다음 기준을 모두 확인한다.

- 모든 페이지가 A4 세로 규격인가?
- Pretendard가 실제 적용되고 한글이 정상 출력되는가?
- 카드뉴스·포스터·영상 장면이 충분히 크게 보이는가?
- 글자·이미지·표에 잘림이나 겹침이 없는가?
- 빈 페이지나 불필요한 페이지 넘김이 없는가?
- 텍스트 검색과 선택이 가능한가?
- 실제 링크가 있다면 정상적으로 작동하는가?
- 기존 콘셉트·타깃·핵심 가치가 유지됐는가?
- 홍보물 3종의 제작 의도와 채널별 집행 계획이 포함됐는가?
- 오픈 전·당일·후 체크리스트가 모두 포함됐는가?
- 미확정 내용을 운영 사실이나 달성 성과처럼 쓰지 않았는가?

모든 페이지를 렌더링해 시각적으로 검수하고, 발견한 문제를 수정한 뒤 최종 PDF와 편집 원본을 제공하라.

## 막혔던 지점

가장 큰 고민은 1시간 반이라는 제한 안에서 내가 만족할 만한 문서를 만들 수 있을지였다. 이전에 제미나이로 만든 문서는 내 기준에 크게 못 미쳤다. 같은 방식을 반복하기보다 이번에는 도구와 작업 방식을 바꿔 보기로 했다.

원하는 보고서의 모습과 내용의 깊이를 함께 전달해야 한다는 점도 중요했다. 레퍼런스만으로는 브랜드 색상이나 보고서의 논리까지 정해지지 않기 때문에, 무엇을 참고하고 어떤 정보를 유지할지 프롬프트에서 따로 정리했다.

## 새롭게 이해한 것

레퍼런스는 내가 원하는 편집 방향을 구체적으로 설명하는 데 도움이 됐다. 여기에 색상·서체·페이지 구성·이미지 배치 기준을 더하니 결과물을 판단할 기준도 분명해졌다.

홍보기획서에는 각 홍보물이 누구에게 어떤 메시지를 전달하고, 어느 채널에서 어떤 행동을 유도할지가 드러나야 한다. 이번에는 이미 만든 홍보물의 제작 의도를 설명하는 것과 실제 집행 순서를 정하는 것을 함께 생각하며 프롬프트를 다듬었다.

이번 경험에서 다시 활용하고 싶은 것은 전체 작업 흐름이다. 레퍼런스 선정 → 브랜드·편집 기준 지정 → 내용과 검수 기준 구체화 → HTML 제작 → PDF 변환의 순서로 진행하니 내가 원하는 보고서에 가까워졌다. 도구와 요청 방식을 함께 바꾼 이번 시도가 만족스러웠고, 다음 문서 작업에서도 이 흐름을 이어가려고 한다.
