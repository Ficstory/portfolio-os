대상 원문: https://ficstory.dev/PM/ 및 이 페이지에서 연결되는 네 프로젝트 상세.

2026년 9월 14일의 배포본을 기준으로, 원문의 방향·프로젝트 순서·주요 본문·역할·수치·기간을 보존한 36페이지 자료입니다. 내비게이션, 반복된 소개, 영상 재생 안내는 문서에 맞게 정리했습니다. 영상은 실제 프레임과 원본 링크로 옮겼습니다.

## 디자인과 편집

- 16:9 가로 문서. 따뜻한 흰색 배경, 검정 본문, 파란 강조색과 얇은 구분선을 사용했습니다.
- 사이트의 Pretendard 대신 Windows에서 사용할 수 있는 맑은 고딕을 사용했습니다. 제목·본문·캡션의 크기와 여백을 일관되게 적용했습니다.
- PPTX의 제목·본문·표·설문 차트는 편집 가능한 요소입니다. 실제 화면·현장 사진·영상 프레임은 이미지입니다.
- 이미지의 종횡비를 유지하고, 긴 본문은 여러 페이지에 나누었습니다.

## 원문 및 실제 자료

- `sources/`: 대문자 `/PM/` 배포본과 네 상세의 HTML·텍스트·접근 기록.
- `content.json`: 페이지별 원고·배치 유형·출처.
- `assets/`와 `deck_assets.json`: 실제 확보 자료 11개와 출처·영상 시각·파일 해시.
- `content_coverage.md`: 원문과 원고 대조 범위 및 예외.
- `build/`: 재생성 코드와 자동 검수 기록. 사용자 제출에는 `output/`의 최종 파일을 사용합니다.

## 사실을 읽는 범위

- 개인 기여와 팀 기여·팀 수상을 구분했습니다.
- 애낌·Play Pick의 예시 데이터 화면은 실제 절감액이나 추천 품질 성과를 증명하지 않습니다.
- 친구 초대방 진입·대기실 프레임을 사용했습니다. 별도 방 생성 완료·코드 입력 과정은 확보한 프레임으로 증명하지 않습니다.
- 부산이음길의 기관 섭외·인터뷰·MVP 선정과 지도 구현 기여는 현재 원문을 따릅니다. 정지 화면만으로 마커 동작 검증이나 사용자 검증 완료를 주장하지 않습니다.

원본 사이트나 앱의 소스 및 배포 상태는 변경하지 않았습니다. 이번 36페이지 파일 제작은 별도 작업이며 기존 12페이지 Canva 디자인에 덮어쓰지 않았습니다.
