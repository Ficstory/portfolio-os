부산의 보행약자와 저시력자를 위해 이동 조건과 접근성 설정을 반영한 길안내 앱입니다.

기간

팀

MY ROLE

역할과 핵심 기여

내 담당
서비스 기획 · 기관 섭외·인터뷰 · MVP 선정 · 프론트엔드 개발
  1. 01서비스를 처음부터 기획하고, 함세상 장애인자립생활센터를 직접 섭외했습니다.
  2. 02센터와의 미팅·인터뷰를 바탕으로 MVP 범위를 선정했습니다.
  3. 03길안내 지도 위 마커를 고정하는 동작과 관련 프론트엔드를 구현했습니다.
  4. 04글자 크기 설정·승인된 제보 표시를 구현하고 관련 명세를 관리했습니다.

초기 기획·인터뷰 / Planning

처음부터 기획하고, 현장 인터뷰로 MVP 범위를 정했습니다.

부산이음길의 초기 서비스 기획을 맡았습니다. 기획을 구체화하기 위해 함세상 장애인자립생활센터를 직접 섭외하고, 2026년 4월 10일 미팅·인터뷰를 진행했습니다. 그 내용을 바탕으로 MVP 범위를 선정했습니다.

경로 비교
여러 경로 선택지와 경사·계단·폭 같은 위험 정보를 확인하려는 요구를 경로 비교·상세·안내 흐름으로 연결했습니다.
사용자 이동 조건
이동 보조기기마다 조건이 다르다는 의견을 사용자 유형 온보딩으로 반영했습니다.
접근성 시설 탐색
화장실·충전기·건물 접근성 정보에 대한 요구를 접근성 필터와 시설 상세 탐색으로 연결했습니다.

지도 개발 / Map development

길안내 지도 화면과 마커 고정 동작을 구현했습니다.

보행약자가 목적지와 이동 정보를 확인하는 길안내 지도 화면을 개발했습니다. 지도 위 선택 핀의 고정 렌더링과 카메라 제스처 동기화를 포함한 관련 프론트엔드 작업을 맡았습니다.

추가 구현 / Additional work

접근성 설정과 제보 표시도 구현했습니다.

글자 크기를 선택하면 즉시 저장·적용되도록 구현하고, 승인된 사용자 제보를 접근성 시설과 구분해 지도에 표시했습니다. 제보를 선택하면 내용을 확인하는 하단 패널로 연결했습니다.

주요 산출물 / Outputs

초기 기획과 MVP 선정, 지도 화면 개발을 산출물로 남겼습니다.

초기 기획·기관 인터뷰
서비스를 기획하고 함세상 장애인자립생활센터를 섭외해 회의·인터뷰를 진행했습니다.
MVP 선정
인터뷰에서 확인한 이동 조건을 경로 비교, 사용자 유형 온보딩, 접근성 시설 탐색 범위로 연결했습니다.
지도 프론트엔드
길안내 지도 화면과 마커 고정 동작을 구현했습니다.
추가 구현
글자 크기 설정, 승인된 제보 표시, 관련 명세 관리를 맡았습니다.
